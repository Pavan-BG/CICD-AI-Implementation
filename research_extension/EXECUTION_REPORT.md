# Reproducible execution record (21 November 2026)

## Source and method

The provided PatchRail v0.7.6 archive was preserved. The research extension reads 223 maintained fixture logs paired with expected JSON classifications and 22 specifically enumerated, independently archived public CI logs. The original public descriptions are in `docs/real-world-benchmark.md` and `examples/real-world/README.md`. The 22 real-world cases do not occur in the TF-IDF training index.

Python 3.13 was used in an offline, CPU-only environment. The following commands were executed from the project root:

```bash
python -m research_extension.run --backend none
PYTHONPATH=src python -m pytest -q tests/test_ci_local_first.py tests/test_ci_classify_expansion.py tests/test_realworld_mainstream_logs.py tests/test_unknown_runner_errors.py tests/test_php_test_failure_not_composer.py research_extension/tests
```

The focused original-project and extension test command completed with **198 passed and 695 subtests passed**. This is not a claim that the entire repository test suite has completed.

## Observed clustering outputs

The TF-IDF feature matrix has 223 rows. Preprocessing removes timestamps, hashes, file paths, URLs and numeric tokens. The vectoriser uses English stop words, unigrams and bigrams, `min_df=2`, and sublinear TF weighting. KMeans used 20 initialisations, random state 42, cosine silhouette to choose k from 4 to 8.

| k | Cosine silhouette |
|---:|---:|
| 4 | 0.084063 |
| 5 | 0.094784 |
| 6 | 0.110039 |
| 7 | 0.116222 |
| 8 | **0.132301** |

The chosen cluster sizes are **33, 10, 24, 98, 20, 11, 14 and 13**, respectively. The large cluster with 98 mixed cases demonstrates weak separation. The reviewed names, top eight centroid terms, five example filenames per cluster and dominant fixture classes are included in `cluster_report.json`; `clusters.csv` provides a compact overview.

The 50-row fixture-reference audit produced **39/50** broad-category majority matches. These cases were assessed against the archive's maintained expected labels; they are not independent human annotations. They must not be reported as human inter-rater agreement.

## Fixed 22-case evaluation

The 22 real-world reference labels were mapped from the project maintainer's documented failure narratives into a broad technical taxonomy (stored in `real_world_reference.json`). Using the same cases, the unchanged PatchRail baseline matched **11/22** broad source descriptions; a separate non-LLM TF-IDF nearest-three fixture-label vote matched **9/22**. In **21/22** queries, two or three neighbours shared a KMeans cluster; this does not constitute diagnostic verification because cluster agreement can be misleading. Detailed per-case outputs are in `real_world_22_baselines.csv` and `case_details.json`.

These counts cannot be compared directly to the thesis's earlier MiniLM Version 3 **10/22** result or PatchRail **9/22** result, because the earlier results use a different provisional classification rubric and the original custom scripts were not provided.

## LLM execution boundary

A real small-model adapter and JSON-based diagnosis/verification path are implemented for Ollama (`qwen2.5:0.5b`) or the OpenAI-compatible API (`gpt-4.1-mini`). Unit tests exercise the interface and failure-path validation with a mocked transport. No pretrained LLM weights, Ollama server, API credential, or outbound model-download access were available in the execution environment. An explicit Ollama connection attempt returned **connection refused**, so the adapter correctly recorded `llm_status=incomplete` in a separate test directory. The published offline result file states `llm_status=not_executed`; it contains no fabricated LLM predictions, counts or recommendations.

To complete the professor's V2/V3 requirement, install Ollama and pull the small pretrained model, then run:

```powershell
ollama pull qwen2.5:0.5b
python -m research_extension.run --backend ollama --model qwen2.5:0.5b
```

Once genuinely executed, `summary.json` will include verified-out-of-22 and broad-category-correct-out-of-22 outputs. Category agreement with similar logs is a weak consistency signal, not independent ground truth. The optional generated CI/CD suggestions also require actual model execution, and evaluating similarity to *external repository fixes* requires verified repair commits or issue histories not provided by the PatchRail archive.
